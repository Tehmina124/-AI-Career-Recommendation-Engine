# 📌 Overview

Choosing the right career can be challenging for students and fresh graduates.

The **AI Career Recommendation Engine** uses **Machine Learning** and **Natural Language Processing (NLP)** to analyse a user's skills and interests and recommend the most suitable career path.

The project provides predictions with confidence scores through an interactive **Gradio** web application.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Tehminaanwar543/AI-Career-Recommendation-Engine.git
```

Go to the project folder

```bash
cd AI-Career-Recommendation-Engine
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# 🚀 Run the Project

```bash
python app.py
```

The Gradio interface will automatically open in your browser.
