# 📌 Overview

The **AI Career Recommendation Engine** is a Machine Learning based application designed to help students and professionals discover suitable career paths according to their skills, interests, and technical knowledge.

The system uses **Natural Language Processing (NLP)** techniques and a trained Machine Learning model to analyze user input and predict the most suitable career option.

The application provides an interactive interface using **Gradio** for easy user interaction.

---

# 🎯 Problem Statement

Many students and beginners face difficulty choosing the right career path according to their skills and interests.

This project provides an AI-based solution that recommends suitable career options by analyzing user skills and interests.
